VS06-D1 · TBDY 2018 Table 3.6, §3.6.2.3

B1 weak story — conditional source calculation

The selected ETABS run supplies the B1 result. To calculate from separate sources, select two JSON files. Column and wall areas come from source sections and coordinates. Masonry areas are inferred from load intensity using stated assumptions.

File-based calculations use the selected infill connection and R. Archived runs use their saved assumptions. Initial scenario: Brittle infill. For Ak, 9 cm or 19 cm thickness is inferred from load. The source beam t3 depth is subtracted from story height. Low line loads use the alternative 50% opening scenario. Confirm the masonry shear modulus Gm from test data for design use.
